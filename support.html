FitMatch 고객지원

FitMatch는 무신사·유니클로·ZARA 상품 링크로 내 옷과 실측을 비교하고, 내 옷장과 비교 기록을 보관하는 앱입니다.

문의 및 오류 제보

FitMatch GitHub Issues에서 문의하기. GitHub 계정이 필요할 수 있습니다.

상품 불러오기나 비교 결과에 문제가 있으면 쇼핑몰명, 상품 URL, iPhone·iOS 버전, 재현 절차를 알려주세요. 계정 식별자, 로그인 코드, 개인 실측 등 민감한 내용은 공개 이슈에 적지 마세요.

앱에서 확인할 내용

  • 지원 쇼핑몰의 실제 상품 페이지 링크인지 확인하고 다시 시도해 주세요.
  • 저장 오류가 표시되면 앱을 완전히 종료한 뒤 다시 열어 상태를 확인해 주세요.
  • 회원 탈퇴는 앱의 My 화면에서 진행할 수 있습니다.
