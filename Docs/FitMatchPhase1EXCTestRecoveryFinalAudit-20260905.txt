E. Root cause

1. Production compile blocker

Swift compiler가 measurement dictionary generic 타입을 추론하지 못했다.
조건과 값은 변경하지 않고 타입만 명시해 해결했다.

2. SwiftUI compile blocker

foregroundStyle 삼항식 양쪽 ShapeStyle 타입을 하나로 추론하지 못했다.
같은 조건과 같은 색상을 concrete Color로 명시했다.

3. Server authority test failure

테스트가 제거된 local reference selection authority를 기대했다.
production local fallback은 부활시키지 않고 현재 server discovery 계약으로 테스트를 교체했다.

4. Headless fixture failure

현재 비교 flow는 load 후 server reference plan과 authorization에서 추가 resolve/runtime/candidate RPC를 수행한다.
strict test remote가 필요한 응답 envelope를 충분히 제공하지 못해 fail-closed 됐다.
production의 fail-closed 동작은 유지하고 test fixture만 현재 계약에 맞췄다.

5. ZARA full-run failure

첫 temporary code mirror에 test가 요구하는 Docs/Research 및 ZARAAudit fixture 파일이 없었다.
parser assertion까지 도달하기 전에 file-not-found가 발생했다.

증거:
- complete current-candidate mirror ZARA class: 41 PASS / 0 FAIL / 3 SKIP
- 직전 실패 8개 개별 실행: 8/8 PASS
- exact 9d88807 detached baseline ZARA class: 41 PASS / 0 FAIL / 3 SKIP

6. UI failure

대표 test01이 Phase 1E 이전 9d88807 baseline에서도 초기 onboarding root wait에서 동일 실패했다.
Phase 1E measurement gate 또는 link registration path에 도달하기 전 실패이므로 이번 candidate의 production regression이 아니다.
