# 내가 할 일 — 이번 테스트 준비

**최신:** [Resume15Report.md](Resume15Report.md). 개발 계정 초기화는 사용자 승인 후 자동 승인 검토에서 차단되어 미적용입니다. Apple 계정도 정상 세션이 있으면 사용할 수 있습니다. 실제 DB는 두 계정의 정상 인증과 이후 seed 검증이 남아 있습니다. 아이폰 관리자 로그인만으로 Mac 테스트가 연결되지는 않습니다.

**지금 필요한 도움은 아래 1번뿐입니다.** 2번 아이폰 확인은 나중에 할 별도 작업이며 이번 자동 테스트 준비 완료 조건에 포함하지 않습니다.

**자동 테스트와 DB 확인은 아스트라가 합니다. 나는 로그인 도움과 아이폰 확인만 하면 됩니다.**

## 1. 자동 테스트를 위해 도와줄 일

- [ ] 아스트라가 안내하면 **테스트 계정 2개의 정상 로그인**을 도와주기.
  - 계정 준비·연결 설정·테스트 실행은 아스트라 담당.
  - 비밀번호나 인증 토큰은 채팅에 보내지 않기.
- [x] 점수 계산 기준 결정: 사용자 위임에 따라 기존 검증된 산술 규칙으로 확정. 추가 결정 불필요.

## 2. 나중에 할 일 — 이번 준비 범위 밖

**아스트라가 확인해 준 QA 앱·개발 DB로 진행. 테스트용 옷과 기록만 사용.**

| 체크 | 내가 해볼 것 | 정상이면 이렇게 됨 |
|---|---|---|
| ☐ | Apple로 로그인 | 로그인되고 앱 사용 가능 |
| ☐ | 무신사·유니클로·자라에서 상품 공유 → FitMatch 선택 | 선택한 상품을 정확히 불러옴 |
| ☐ | 링크로 내 옷 추가 → 사이즈 선택 → 저장 | 내가 선택한 상품·사이즈·받아온 실측이 보임 |
| ☐ | 직접 입력으로 옷 추가 → 수정 → 앱을 완전히 종료하고 다시 열기 | 수정한 내용 그대로 남음 |
| ☐ | 상품 비교 → 비교할 내 옷 선택 | 결과가 표시되고 기록에서 다시 열림 |
| ☐ | 다른 사이즈 선택 → 다른 내 옷 선택 → 다시 다른 사이즈 선택 | 방금 고른 옷·사이즈로 결과가 바뀜 |
| ☐ | 비교 상품을 보유한 옷으로 등록 | 등록할 때 선택한 사이즈로 내 옷장에 저장됨 |
| ☐ | 테스트 옷과 비교 기록을 각각 삭제 | 선택한 것만 삭제되고 다른 옷·기록은 남음 |
| ☐ | 목록 스크롤·버튼·뒤로 가기·삭제 스와이프 사용 | 누를 수 없거나 화면이 멈추거나 엉뚱한 동작이 없음 |

**점수가 정확한지 손계산하거나 DB를 열어볼 필요는 없습니다. 그건 아스트라 담당입니다.**

## 3. 결과는 이렇게 알려주기

```text
설치한 앱 버전:
잘된 항목: 전부 / 위 표의 항목명
문제 항목:
누른 순서:
기대했던 결과:
실제로 나온 결과:
사용한 상품 링크:
스크린샷 또는 짧은 영상: 문제가 있을 때만
```

앱 삭제·재설치, 다른 기기 동기화 확인이 추가로 필요하면 아스트라가 자동 검사 결과를 보고 별도로 안내합니다. 지금 임의로 앱을 삭제할 필요는 없습니다.
