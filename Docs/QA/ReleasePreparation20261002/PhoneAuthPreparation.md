# 아이폰에서 가능한 준비 — 로그인

**Supabase 관리 사이트 로그인만으로 Mac 자동 테스트가 로그인되지는 않습니다.**

필요한 것은 개발DB의 **버려도 되는 테스트 계정2개**입니다. 기존 개인 계정이나 운영 계정은 사용하지 않습니다.

## 아이폰에서 확인할 것

1. Supabase에서 개발 프로젝트 **FitMatch — hnkplvyegonlhumlejst**를 엽니다. **FitMatch_PROD는 선택하지 않습니다.**
2. Authentication → Users에서 이미 만든 전용 테스트 계정2개가 있는지 확인합니다.
3. 없다면 아직 기존 계정을 변경하거나 인증 설정을 끄지 말고, **“테스트 계정 없음”**이라고 알려주세요. 계정 생성은 개발환경 준비로 허용되지만, 현재 제 연결에는 Auth관리 생성 도구/로그인된 관리브라우저가 없습니다.

## Mac 실행에 필요한 연결

계정이 있어도 이 Mac에 정상 로그인 세션을 만드는 단계가 한 번 필요합니다. 준비된 `scripts/release_qa_session.py --sign-in`이 비공개 입력으로 로그인하고 저장소 밖의 권한제한 임시파일을 만듭니다. 이 단계는 Mac 접근이 가능할 때 진행합니다. 아이폰 관리사이트의 로그인 정보를 가져오거나 기존 앱 세션을 추출해서 대신하지 않습니다.

**비밀번호·토큰·service_role 키를 채팅에 보내지 마세요.** 계정이 있는지 여부만 알려주면 됩니다. 직접 DB나 점수를 검사할 필요는 없습니다. 인증이 연결되면 실제 검사는 제가 진행합니다.
