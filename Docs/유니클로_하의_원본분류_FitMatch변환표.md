# 유니클로 하의 원본 분류 → FitMatch 옷장 분류 변환표

작성 기준: 2026-07-28

## 확인한 문제

유니클로 상품 `스트레이트진`의 원본 분류는 다음과 같다.

```text
팬츠 > 진(청바지) > 스트레이트
```

유니클로 파서는 이 상품을 정상적으로 `하의 / 데님`으로 감지했다. 그러나 옷장 canonical 변환 규칙에 `진(청바지)`, `청바지`, 일반 한국어 `팬츠`가 긴바지 키워드로 등록되어 있지 않아 마지막 기본값인 `other_bottoms`로 떨어졌다. `other_bottoms`는 옷장 화면에서 `기타`로 표시되므로 사용자가 긴바지를 기타 하의로 보게 됐다.

## 수정 후 저장 결과

| 구분 | 저장 값 |
|---|---|
| 플랫폼 원본 경로 | `팬츠 > 진(청바지) > 스트레이트` |
| FitMatch 대분류 | `하의` (`bottoms`) |
| FitMatch 세부 분류 | `긴바지` (`long_pants`) |
| 의복 종류 | `데님` |
| 길이 종류 | `긴바지` |
| 핏/실루엣 원본 정보 | `스트레이트` 원본 경로로 보존 |

`데님`과 `긴바지`는 서로 대체하는 값이 아니다.

- `긴바지`: 옷장 탐색과 길이 정책에 쓰는 canonical 세부 분류
- `데님`: 같은 종류의 옷을 찾는 의복 특성
- `스트레이트`: 플랫폼 원본 분류 경로에 보존되는 실루엣 정보

## 유니클로 하의 변환 우선순위

아래 규칙은 위에서부터 먼저 일치하는 항목을 적용한다.

| 유니클로 원본 경로/키워드 | FitMatch 세부 분류 | 비고 |
|---|---|---|
| `숏 팬츠`, `쇼트 팬츠`, `반바지`, `쇼츠`, `버뮤다`, `shorts`, `short pants` | 반바지 (`shorts`) | 긴바지보다 먼저 판정 |
| `크롭`, `cropped` | 크롭 팬츠 (`cropped_pants`) |  |
| `7부`, `three quarter`, `3/4 pants` | 7부 팬츠 (`three_quarter_pants`) |  |
| `9부`, `ankle`, `nine tenths` | 9부 팬츠 (`nine_tenths_pants`) |  |
| `점프수트`, `오버올`, `jumpsuit`, `overall`, `기타 하의` | 기타 하의 (`other_bottoms`) | 명시적으로 기타인 경우 |
| `진(청바지)`, `청바지`, `데님 팬츠`, `denim`, `jeans` | 긴바지 (`long_pants`) + 데님 특성 | 이번 문제의 대상 |
| `팬츠`, `바지`, `pants`, `trousers` | 긴바지 (`long_pants`) | 짧은 길이 규칙이 먼저 제외된 일반 팬츠 |
| `코튼 팬츠`, `치노`, `슬랙스`, `조거`, `트레이닝`, `슈트 팬츠` | 긴바지 (`long_pants`) | 원본 종류 특성은 별도 보존 |
| `긴바지`, `롱 팬츠`, `long pants` | 긴바지 (`long_pants`) |  |
| 위 어느 규칙에도 해당하지 않음 | 기타 하의 (`other_bottoms`) | 사용자 확인 필요 |

## 로직이 실제로 동작하는 순서

분류에는 상품명만 쓰지 않는다. 다음 값을 합쳐 소문자 검색 문자열을 만든 뒤 위 우선순위대로 검사한다.

1. 파서가 정한 대분류가 `하의`인지 확인한다.
2. 플랫폼 원본 depth 1~4와 원본 경로를 합친다.
3. 반바지 키워드를 가장 먼저 찾는다.
4. 이어서 크롭, 7부, 9부, 점프수트/기타를 찾는다.
5. 앞 단계에 해당하지 않고 `팬츠`, `바지`, `진(청바지)`, `청바지`, `데님`, `슬랙스` 등의 키워드가 있으면 긴바지로 정한다.
6. 어느 규칙에도 없으면 안전한 기본값인 기타 하의로 둔다.

따라서 일반 단어 `팬츠`가 포함되어도 더 구체적인 `쇼트팬츠`가 먼저 발견되면 반바지가 된다.

### `팬츠 > 치노팬츠 > 와이드` 판정 추적

```text
원본 depth: 팬츠 / 치노팬츠 / 와이드
1. 반바지 키워드 없음
2. 크롭·7부·9부 키워드 없음
3. 점프수트·기타 키워드 없음
4. 일반 팬츠 키워드 있음
결과: bottoms / long_pants → 하의 / 긴바지
```

`와이드`는 바지통의 실루엣이지 길이가 아니다. 따라서 `와이드`만으로 반바지나 긴바지를 결정하지 않고, 원본 경로의 길이/팬츠 키워드를 사용한다.

### `팬츠 > 쇼트팬츠 > 와이드` 판정 추적

```text
원본 depth: 팬츠 / 쇼트팬츠 / 와이드
1. 반바지 키워드인 쇼트팬츠 발견
결과: bottoms / shorts → 하의 / 반바지
```

이 경우에도 `팬츠`가 들어 있지만 반바지 규칙이 먼저 끝나므로 긴바지 규칙까지 내려가지 않는다.

## 대표 사례

| 유니클로 원본 경로 | 상품 예 | 예상 옷장 표시 |
|---|---|---|
| `팬츠 > 진(청바지) > 스트레이트` | 스트레이트진 | 하의 / 긴바지 |
| `팬츠 > 진(청바지) > 슬림` | 슬림스트레이트진 | 하의 / 긴바지 |
| `팬츠 > 진(청바지) > 와이드` | 와이드진 | 하의 / 긴바지 |
| `팬츠 > 치노팬츠 > 와이드` | 와이드치노팬츠 | 하의 / 긴바지 |
| `팬츠 > 쇼트팬츠 > 와이드` | 와이드핏쇼트팬츠 | 하의 / 반바지 |
| `팬츠 > 반바지` | 반바지 | 하의 / 반바지 |
| `팬츠 > 쇼츠` | 쇼츠 | 하의 / 반바지 |
| `팬츠 > 버뮤다` | 버뮤다팬츠 | 하의 / 반바지 |
| `팬츠 > 크롭` | 크롭팬츠 | 하의 / 크롭 |
| `팬츠 > 9부` | 앵클팬츠 | 하의 / 9부 |
| `팬츠 > 점프수트` | 점프수트 | 하의 / 기타 |

## 내 옷장에서 확인할 값

새로 저장한 유니클로 스트레이트진 또는 와이드치노팬츠는 다음처럼 보여야 한다.

```text
분류: 하의 / 긴바지
원본 카테고리: 팬츠 > 진(청바지) > 스트레이트
또는: 팬츠 > 치노팬츠 > 와이드
```

Debug 로그에는 다음 값이 나와야 한다.

```text
closet category: 하의 / 긴바지
closet taxonomy: bottoms / long_pants
```

과거 버전에서 이미 `기타`로 저장된 항목은 저장 당시 값이 남아 있을 수 있다. 해당 항목은 분류를 편집하거나 수정된 빌드에서 다시 저장해 확인한다.
