- actual-size/size-chart HTTP 200이어도 data null, 빈 sizeChart, 핵심 치수 누락은 성공으로 세지 않았다.
- 원본명 별칭과 의미가 불명확한 열은 추정 대응으로만 기록했다.
- 카테고리 HTML에 노출된 현재 상품만 사용했으며 품절 이력 상품을 별도 탐색해 성공 표본으로 교체하지 않았다.
- 출시 전 확인: 실제 앱 파서로 본 CSV의 실패·별칭 유형을 재현 검증하고, 가슴 단면/둘레 및 총장/인심 의미를 카테고리별로 구분해야 한다.
- 출시 차단 가능성: 치수 API 빈 응답, 핵심 열 부재, 카테고리·성별 근거 부재, 색상 코드별 치수 응답 차이.
- 출시 후 보완 가능: 신규 별칭, 할인·품절 UI 문구, 추가 치수 보존.
- HTML 치수표·이미지 OCR은 전체 상세 콘텐츠를 별도 렌더링/OCR하지 않아 확인할 수 없는 경우가 있다.
