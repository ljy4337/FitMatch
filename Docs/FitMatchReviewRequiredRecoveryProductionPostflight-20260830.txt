=============

PASS

Deployed precedence:

1. Global NOT_APPLICABLE → blocked.
2. Global CONFIRMED → GLOBAL_CONFIRMED authority.
3. Global REVIEW_REQUIRED + current owned valid active override →
   PERSONAL_CONFIRMED / USER_EXPLICIT.
4. Global REVIEW_REQUIRED without valid active override → REVIEW_REQUIRED.

The effective resolver only considers personal rows with cleared_at IS NULL.
Therefore a cleared selection cannot be comparison authority and cannot later surface
as current SUPERSEDED_MATCH or SUPERSEDED_CONFLICT. With a later Global CONFIRMED it
returns plain GLOBAL_CONFIRMED. An active old override may retain superseded evidence,
but Global controls all future comparisons.

Staleness is fail-closed against product input fingerprint, evidence fingerprint,
resolver version, candidate-set hash, selected candidate, and revision. Reselect
recomputes the latest server contract, requires the current revision, increments the
revision, records evidence, and replaces only the user's future effective projection.
Clear marks that projection inactive, records CLEARED evidence, and does not rewrite
history. Neither operation updates global Product classification.
