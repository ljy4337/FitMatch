## 12번 분석

- 기준 상품: 유니클로 E492123
- 비교 상품: 유니클로 E488200, 코듀로이쇼트재킷
- 앱 화면은 멈추지 않았다. 지정 기준 상품 대신 무신사 코트를 `사용자 선택 확장 비교 · 길이·세부 종류 차이 · 공통 실측 4개` 후보로 표시했다.
- 이는 비교 정책에 따른 수동 확장 비교 UX다.
- 최초 자동화는 지정된 기준 상품명만 찾도록 구현돼 실제 표시된 확장 후보를 선택하지 못했다.
- 결론: 앱 결함으로 확정하지 않으며 자동화 하네스 결함으로 분류한다.
- 보완: 지정 후보가 없으면 화면에 표시된 실측 호환 후보를 선택하고, `추천 결과 아님`도 정상 차단 결과로 인정하도록 UI 테스트를 수정했다.
