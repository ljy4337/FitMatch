# FitMatch 개인정보 처리방침 초안

상태: 공개 전 검토본  
기준 앱: FitMatch `connectDB`, 2026-08-20 코드
시행일: `[출시일 입력 필요]`

> 이 문서는 현재 앱 코드와 개인정보 매니페스트를 기준으로 작성한 공개용 초안입니다. 공개 전 운영자명, 지원 이메일, 공개 URL, 시행일을 확정해야 합니다. 대괄호 항목이 남은 상태로 앱이나 웹에 게시하지 않습니다.

## 1. 처리하는 정보

FitMatch는 Apple 로그인을 통해 계정을 생성하며, Supabase 인증 서비스에서 계정 식별자와 사용자가 공개에 동의한 이메일을 처리합니다. 사용자가 앱 기능을 이용할 때 다음 정보가 기기와 FitMatch 서버에 저장될 수 있습니다.

- 내 옷장 정보: 상품명, 브랜드, 의류 분류, 보유 사이즈, 의류 실측, 핏 메모, 만족도, 기준 옷 여부
- 상품 및 비교 정보: 사용자가 입력하거나 공유한 무신사·유니클로·ZARA 상품 URL, 상품 정보, 사이즈표, 선택 옵션, 비교 결과와 비교 기록
- 앱 설정 및 로컬 품질지표: 온보딩 완료 여부, 즐겨찾기·분류 보조 설정, 앱 실행·파싱·비교·옷장 저장 횟수와 같은 집계 카운터
- 계정 정보: Supabase 사용자 ID, Apple 로그인 식별자, 사용자가 공개에 동의한 이메일

로컬 품질지표에는 상품명, 상품 URL, 상품 ID, 실측값, 사진, 사용자 식별자가 포함되지 않습니다.

사이즈표 사진을 선택하면 iOS 시스템 사진 선택기로 사용자가 고른 이미지 한 장을 기기 안에서 일시적으로 불러와 Apple Vision으로 문자와 실측을 인식합니다. 선택한 원본 사진은 FitMatch의 내 옷장이나 비교 기록에 저장하지 않으며 FitMatch 서버로 전송하지 않습니다.

## 2. 이용 목적

- 사용자가 등록한 옷과 쇼핑 상품의 실측 비교
- 호환되는 의류 분류와 비교 대상 선택
- 추천 사이즈, 부위별 차이, 비교 근거와 신뢰도 표시
- 내 옷장, 기준 옷, 비교 기록과 사용자 설정 유지
- 로그인 세션 유지와 여러 기기 간 사용자 데이터 복원
- 앱 기능의 성공·실패 비율을 기기 안에서 집계하여 향후 품질 개선 기능에 대비

## 3. 외부 통신과 제3자 서비스

사용자가 무신사, 유니클로 또는 ZARA 상품 URL을 입력하거나 공유하면 FitMatch는 해당 쇼핑몰의 상품 정보, 이미지 및 사이즈 정보를 불러오기 위해 해당 쇼핑몰 서버에 요청합니다. 이 과정에서 일반적인 인터넷 통신에 필요한 IP 주소, 요청 시각 등의 네트워크 정보가 해당 쇼핑몰에 전달될 수 있으며, 해당 쇼핑몰의 개인정보 처리방침이 적용될 수 있습니다.

계정 인증과 옷장·비교 데이터 저장 및 동기화에는 Supabase를 사용합니다. 광고 SDK, 제3자 분석 SDK 및 사용자 추적 기능은 사용하지 않습니다.

## 4. 저장 위치와 보관 기간

정보는 사용자의 기기 또는 앱과 공유 확장이 함께 사용하는 iOS 앱 그룹 저장소와 FitMatch의 Supabase 서버에 보관됩니다. 사용자가 개별 항목을 삭제하거나 회원 탈퇴를 실행할 때까지 유지될 수 있습니다. 공용 쇼핑몰 상품 카탈로그와 법령상 보관 의무가 있는 비식별 기록은 사용자 계정과 분리해 유지될 수 있습니다.

앱 삭제만으로도 관련 로컬 데이터가 모두 제거되는지는 iOS의 백업·복원 설정에 따라 달라질 수 있습니다. 사용자는 iOS 설정과 백업 관리 기능을 통해 기기 백업을 관리할 수 있습니다.

## 5. 삭제와 선택권

- 내 옷장 항목과 비교 기록은 앱에서 삭제할 수 있습니다.
- 사진 선택은 iOS 시스템 사진 선택기를 통해 사용자가 직접 결정합니다.
- 앱에 남은 모든 로컬 정보를 제거하려면 앱을 삭제할 수 있습니다.
- My 화면의 회원 탈퇴를 실행하면 Supabase 계정, 사용자 소유 서버 데이터, 기기 내 옷장·비교 기록이 영구 삭제됩니다.
- Apple 로그인 권한은 iPhone 설정의 Apple 계정 > Apple로 로그인에서도 해제할 수 있습니다.

추후 카카오·네이버 등 다른 로그인 수단을 추가할 경우 동일한 FitMatch 계정 삭제 절차를 적용하고, 각 로그인 제공자의 권한 해제 방법을 함께 안내합니다.

## 6. 안전조치

FitMatch는 앱에 관리자용 Supabase 키를 포함하지 않습니다. 사용자 데이터는 인증된 사용자별 RLS/RPC 경계로 분리하고, 관리자 권한이 필요한 계정 삭제는 JWT를 검증하는 서버 함수에서만 수행합니다. 앱과 공유 확장 사이의 정보 전달에는 해당 앱 전용 App Group을 사용합니다.

## 7. 아동의 개인정보

FitMatch는 아동을 대상으로 설계된 서비스가 아니며 아동의 개인정보를 의도적으로 별도 수집하지 않습니다.

## 8. 처리방침 변경

데이터 처리 방식이 변경되면 앱의 개인정보 처리방침, App Store Connect의 앱 개인정보 답변 및 필요한 동의 절차를 함께 갱신합니다. 특히 로컬 품질지표를 서버로 전송하기 전에 전송 항목, 이용 목적, 보관 기간과 삭제 방법을 고지합니다.
