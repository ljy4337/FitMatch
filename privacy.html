FitMatch 개인정보처리방침

시행일: 2026년 10월 3일

처리하는 정보와 목적

FitMatch는 Apple 로그인 계정 식별자와 사용자가 제공한 이메일을 로그인·동기화에 사용합니다. 사용자가 등록한 옷의 상품명, 브랜드, 분류, 선택 사이즈, 실측과 핏 관련 입력을 옷장 및 비교에 사용합니다. 입력·공유한 상품 링크, 쇼핑몰 상품 정보, 사이즈표, 선택 옵션과 비교 결과·기록을 상품 불러오기와 결과 제공에 사용합니다.

옷장·비교 정보는 기기와 FitMatch가 사용하는 Supabase 서버에 저장·동기화될 수 있습니다. 공용 쇼핑몰 상품 정보는 사용자 계정과 분리된 카탈로그로 보관될 수 있습니다. 온보딩 완료 여부 등 앱 설정과 집계형 품질 지표는 기기 안에 저장됩니다.

외부 서비스와 이미지 처리

로그인 및 데이터 저장·동기화에는 Supabase를 사용합니다. 무신사·유니클로·ZARA 상품 링크를 분석할 때 해당 쇼핑몰의 웹 또는 API 서버에 요청하므로 일반적인 네트워크 요청 정보가 전달될 수 있습니다. 광고 SDK와 사용자 추적 기능은 사용하지 않습니다.

사용자가 사이즈표 이미지를 선택하면 iOS 사진 선택기와 Apple Vision으로 기기에서 분석합니다. 선택한 원본 사진은 FitMatch 서버에 업로드하거나 옷장·비교 기록에 저장하지 않습니다.

보관·삭제와 선택권

옷장 항목은 앱에서 삭제할 수 있습니다. 비교 기록을 목록에서 숨겨도 서버 원본이 즉시 영구 삭제되는 것은 아닙니다. 회원 탈퇴는 인증 계정 삭제와 계정에 연결된 사용자 소유 서버 데이터 삭제를 실행합니다. 공용 카탈로그와 법령상 보관이 필요한 기록은 계정과 분리되어 남을 수 있으며, 서버 백업에는 삭제 전 정보가 백업 보관 정책에 따라 일시적으로 남을 수 있습니다.

Apple 로그인 권한은 iPhone의 Apple 계정 설정에서 해제할 수 있습니다. 앱 삭제만으로 서버 계정은 삭제되지 않으므로 계정 삭제를 원하면 앱의 회원 탈퇴를 이용해 주세요.

보호와 변경 안내

FitMatch는 앱에 관리자용 Supabase 키를 포함하지 않습니다. 사용자 데이터 접근에는 인증과 서버 권한 검사를 적용합니다. 처리 방식이 바뀌면 이 페이지와 앱 안내, App Store 개인정보 공개 내용을 갱신합니다.
