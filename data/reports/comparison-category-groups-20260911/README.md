# FitMatch 쇼핑몰 카테고리 비교 그룹 제안

> 실제 수집 API JSON 기준의 비교 후보 지도입니다. DB/Swift에 적용된 확정 정책이 아닙니다.

## 그룹

- **A**: 일반 상의
- **B**: 아우터
- **C**: 팬츠·쇼츠·레깅스
- **D**: 스커트
- **E**: 원피스·점프수트·커버올
- **F**: 이너웨어·홈웨어
- **X**: 비교 제외
- **R**: 혼합·검토

| 쇼핑몰 | 정상 상품 | API 카테고리 노드 | 비교 가능 | 제외 | 검토 |

- 셀 값은 `카테고리 노드 수/상품 수`입니다.
- 여러 그룹에 들어가는 노드가 있어 그룹별 합계는 전체보다 클 수 있습니다.
- JSONL은 프로그램 입력용, CSV는 사람이 검토·수정하기 위한 파일입니다.
- 원본 수집 JSON, Swift, SQL, DB는 변경하지 않았습니다.
